# ぼくの GRAND RACE

4〜5歳向けの、オリジナル車両で走る3Dレースゲームです。WebGL 1で描画し、GitHub Pagesに静的ファイルとして配置できます。実行時の外部ライブラリ・外部ホストへの通信・広告・課金・アナリティクス・個人情報の入力や送信はありません。

公開URL：<https://test553378.github.io/my-drive/>

## Ver.4.2 の画質検証（Phase 1・2）

[車1台・コース1つの3D試作を開く](https://test553378.github.io/my-drive/graphics-lab/)。外部GLB車両、実写由来のPBR路面、HDRI反射・照明、動く車輪と実際の影を確認できます。高画質／標準／軽量、近接回転ビューと走行、旧版との同じ48万ピクセルの比較画像、端末内のFPS・読込エラー診断を用意しています。

これは画質を評価するための別ページです。既存ゲームの全車両への展開、通常操舵の中央復帰廃止、AI・難易度の改修は評価後のPhase 3以降です。試作はWebGL 2と初回オンライン読込が必要です。現行ゲームのWebGL 1・オフライン機能はそのままです。

[Phase 1 現状調査](docs/V42-PHASE1.md) ／ [Phase 2 実装・検証](docs/V42-PHASE2.md) ／ [素材と利用条件](graphics-lab/credits.html)

試作の再ビルド：`npm ci && npm run build:graphics`。生成物と記録したアセットのハッシュをCIで検証します。

## Ver.6 の変更（添付の統合要件を反映）

- **8台・7カテゴリー**：既存のNOVA R／AERO Sにトラック、バス、ヘルメット着用ライダー付きバイク、パトカー、救急車、消防車を追加しました。全車が選択・回転プレビュー・パーツ変更に対応し、加速・速度・旋回・ブレーキ性能と当たり判定が異なります。緊急車両には速度に影響しないサイレンと警光灯があります。
- **4つの閉じた3Dコース**：初級／高低差・森林・トンネルのマウンテン／建物・交差点・横断歩道のシティ／長い直線・複合コーナー・シケイン・観客席のグランプリ。地図と全体プレビュー、各周8チェックポイント、脱輪時の復帰を実装しました。難しいコーナーでは速度を抑えると外側へ流れにくくなります。
- **パンクと修理**：回避できる配置のタイヤ・石・木箱・バリケードに強く当たると、近い車輪がつぶれ、車体が揺れます。最高速度60%、加速・操舵低下、ターボ停止。緑の修理エリアへ自動誘導し、約3秒停止して修理します。手動操舵もできます。
- **歩行者とブレーキ**：シティの横断歩道に事前警告付きの歩行者が登場します。接触すると車が3秒停止し、タイムへ10秒を一度加算し、歩行者は安全な歩道へ移動します。流血・負傷・吹き飛び表現はありません。最終順位も加算時間を反映します。待てばペナルティはありません。
- **タッチ操作**：ブレーキを追加し、複数の指を個別に管理します。ゲーム操作領域のダブルタップ拡大を抑え、OSのアクセシビリティ拡大は制限しません。
- 左右方向の修正、曲面車体・反射・ホイール・車体姿勢・追従カメラ、描画品質の自動調整、WebGL診断・復旧機能を維持しました。コース切替時に古いGPUメッシュを破棄し、車体キャッシュも上限を設けています。

[Ver.6 の要件対応・検証報告と実機チェック項目](docs/V6-VERIFICATION.md) ／ [Ver.5の左右操作の原因調査](docs/V5-VERIFICATION.md)

グランツーリスモのような落ち着いた追従カメラや車体表現を参考にした軽量な独自実装です。実在の車種・ロゴ・ゲーム素材は使用していません。家庭用ゲーム機相当の写実表現ではありません。**iPad第9世代の実機での性能・発熱・安定性は未検証です。** 自動テストのiPad相当の画面寸法は実機のA13 GPUやSafariを再現しません。

## あそびかた

1. 車の形、色、タイヤ、ボディ、エアロとコースを選びます。車のプレビューは指で左右にドラッグして回転できます。
2. 「レース スタート！」をタップ。アクセルと道に沿った走行は自動です。
3. ◀／▶を押す間だけ左右へ移動します。手を離すとゆっくり中央へ戻ります。両方を同時に押すと中央復帰が働きます。
4. ⚡ターボはお好みで。ゲージが回復すると再び使えます。ターボなしでも2周を完走できます。
5. ✋ブレーキで停止、離すと自動加速。歩行者には道をゆずり、パンクしたら緑の修理エリアへ進みます。
6. Ⅱで一時停止、▶で再開。「ガレージへ」で車やコースを選び直せます。
7. PCは左右キー・下キー（ブレーキ）・スペース（ターボ）・Escape（一時停止）に対応します。プレビューにフォーカスを当てると左右キーで車を回転できます。

最初はミュートです。音声はオンにした際だけ初期化し、利用できなくてもレースは動作します。OSの「視差効果を減らす」に相当する設定で車体の揺れと画角変化を抑えます。

## 安定性と動作診断

右上の「？」、またはエラー画面の「おとなのかたへ：動作診断」を開きます。走行中に開いた際はレースが一時停止します。診断は端末内でのみ扱い、自動保存・自動送信はありません。コピーとJSON保存は利用者の操作時だけ行います。

- `context-unavailable`：WebGLコンテキストが取得できなかった。GPU・iPadOS・Safariのどれが原因かはこの情報だけでは断定できません。
- `shader-compile-failed` / `program-link-failed`：対象シェーダーと実際のコンパイラー／リンカーログを記録します。
- `render-failed`：描画中の例外やWebGLエラーを検出しました。
- `context-lost` / `context-restored`：喪失とGPUリソース再構築を記録します。喪失時はレースと描画を止め、復帰後の再開にはタップが必要です。
- `asset-load-failed`：ローカルのスクリプトやCSSの読込失敗を検出しました。

診断には選択パーツ、画面に投影された車体とコース中央の位置、描画頂点数・バッファサイズ・画質の変更も含みます。UA・端末識別子・Cookie・位置情報は収集しません。機種・iPadOS・Safari／ホーム画面起動の別・発生操作は報告時に手動で添えてください。軽い画質はURL末尾の `?quality=low` でも選べます。

Ver.3にあった共有uniform `uEye` の精度不一致による初期化失敗はVer.4で修正しています。[当時の調査・検証記録](docs/VERIFICATION.md)を参照してください。

## GitHub Pages

既存の設定（`main` ブランチ、`/(root)`）で利用できます。ビルド・サーバー・APIキーは不要です。配置する実行ファイル：

```text
index.html
style.css
diagnostics.js
game.js
driving.js
vehicle-config.js
input.js
tracks.js
world.js
race-config.js
collisions.js
hazards.js
damage.js
pedestrians.js
race-metrics.js
actors.js
camera.js
garage.js
vehicles.js
service-worker.js
manifest.webmanifest
icon.svg
.nojekyll
```

すべて相対パスで、`/my-drive/` のサブディレクトリでも動作します。JavaScriptモジュールを使うため、`file://` での直接起動には対応しません。

初回のオンライン読み込みで必要ファイル21個を同じ版のキャッシュへ保存します。2回目以降はオフライン起動に対応しますが、Safariによるデータ削除・キャッシュ退避後にはオンライン読み込みが必要です。初回オフライン起動はできません。更新時にこのゲームの古いキャッシュだけを削除します。アプリ更新時は `service-worker.js` の `CACHE_NAME` も更新してください。

旧版のキャッシュが表示される場合は、オンラインで再読み込みして更新を取得した後、一度ページ／ホーム画面アプリを閉じて開き直してください。診断の `version` が **`6.0.0`** であることを確認してください。

## 開発・自動テスト

Node.js 22以上を使用します。npm依存は開発・テスト専用です。

```sh
npm ci
npm run check
npm test
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

ローカル確認：

```sh
node tests/serve.js
# http://127.0.0.1:8765/my-drive/ を開く
```

単体テストは全32車両×コースの2周完走・修理誘導、各車輪のパンク、歩行者の事前警告・接触・二重加算防止、停止・時間加算を反映した順位、多指入力、左右方向・車両性能などを検証します。ブラウザテストは実シェーダー・描画、パーツによる実フレームバッファの変化、選択パーツでの出走、iPad第9世代相当の画面寸法、診断・コンテキスト復帰・2周完走を検証します。

Linux版Playwright WebKitでは、ゲームを含まない最小ページでもオフラインナビゲーションが内部エラーになるため、その1ケースを理由付きで除外しています。Chromiumのオフライン起動と、両ブラウザの全ファイルキャッシュは別に検証します。`node tests/repro-webkit-offline.js` で最小構成を確認できます。Safari実機のオフライン起動は未検証です。
