ぼくのドライブ - お子さん向け車運転ゲーム (試作版 v1)

【遊び方】
1. 「あそぶ！」をタップすると車が自動で前進します。
2. 左右の大きなボタンを押し続けると車を左右に動かせます。
3. 「プップー」はクラクションです。上の「のはら」を押すと街・海に切り替わります。
4. 星を取ると数字が増えます。ゲームオーバーはありません。
5. 車の色を変えたい場合はページを再読み込みしてください。

【Windows PCで試す】
index.html をダブルクリックして Edge/Chrome で開いてください。
矢印キー（← →）でも操作できます。音はスペースキーでも鳴ります。

【iPadでSafariから使う】
重要: iPadの「ファイル」アプリでHTMLを単にプレビューする場合、JavaScriptが制限され、
ゲームが動かないことがあります。確実なのは下記のようにHTTPSで公開してSafariで開く方法です。

1. GitHubに無料のアカウントを作ります。
2. 新しいpublicリポジトリを作成し、同梱の5ファイルをルートへアップロードします。
3. Settings → Pages → Deploy from a branch → main / (root) → Save に設定します。
4. 表示された https://(ユーザー名).github.io/(リポジトリ名)/ にiPadのSafariでアクセスします。
5. Safariの共有メニュー → 「ホーム画面に追加」 → 必要なら「Webアプリとして開く」をON → 追加。
6. 初回読み込み後は、サービスワーカーのキャッシュが残っている限りオフラインでも利用できます。

注意: GitHub Pagesで公開した場合、URLを知っている人など他の人もゲームにアクセスできます。
本作には個人情報・写真・広告・解析・外部送信は組み込んでいません。
自宅の家族だけで遊ぶ場合、App Storeへの登録もApple Developerの年会費も不要です。

【ファイル構成】
index.html           ゲーム本体。ネットなしでも単体でPC上で実行可

manifest.webmanifest ホーム画面表示の設定
icon.svg             アイコン
README.txt           この説明書
