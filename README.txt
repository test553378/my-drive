ぼくの GRAND RACE Ver.3 / 2026年11月7日
========================================

【変更内容】
- WebGLを用いた3Dのレーシングゲーム (外部ライブラリ不要)
- エアロパーツ、ヘッドライト、ウイング、ホイールを含む立体スポーツカー
- 光沢のある車体、ガラス反射、路面ノイズ、空のグラデーション
- 路肩、縁石、ガードレール、スタンド、建物、照明と樹木
- 低めの追従カメラ、ステア時の車体ロール、加減速時のピッチ
- タイヤ回転、加速・ブースト時の画角変化、衝突時の画面揺れ
- 4台のライバルと2周のレース。4〜5歳向けの大きな左右ボタン
- 音声のオン・オフ。初期設定はミュート
- 広告・課金・アナリティクス・外部ライブラリ・外部通信なし
- 車両はオリジナルであり、実在する車種のロゴを使用していません

【iPadでアップデートする方法】
1. このZIPをWindowsで解凍します。
2. GitHubで現在公開しているリポジトリを開きます。
3. Add file → Upload files から index.html, service-worker.js,
   manifest.webmanifest, icon.svg をアップロードし同名ファイルを更新します。
4. Commit changesで確定します。既存のGitHub Pages URLをiPad Safariで開きます。
5. 古い版が表示されたらSafariで再読み込みします。ホーム画面アプリも
   完全に終了して再起動します。必要に応じてホーム画面に追加し直します。

【操作方法】
◀ ▶ ：左右にハンドルを切る。押し続ける間だけ操作します。
⚡ TURBO：加速ボタン。ゲージが60%以上で使用可能です。
右上のスピーカー：サウンドのオンオフ。
右上のⅡ：一時停止、再開。
PCの場合は左右カーソルキー、スペースキーでも操作できます。
アクセルは自動。路肩に出ると減速。接触時は減速のみで失格はありません。

【動作・制限】
初回はGitHub Pagesの公開ページへのアクセスが必要です。
2回目以降はキャッシュによりオフラインでも動く構成ですが、
端末のキャッシュ保存状況やSafariの設定によっては保証されません。
WebGL対応ブラウザが必要です。iPad実機での動作は未確認です。
重く感じる場合はSafari以外のタブを閉じ、低負荷状態でお試しください。
あくまで独自実装の3Dゲームであり、家庭用レースゲームの実写品質ではありません。
公開リポジトリには個人情報や家族写真を置かないでください。
