## 実装

- `roads.js`：各コースの本線7エッジと、3か所のアクセス路・追跡環状路・合流路を接続。全経路を双方向に実走できる。物理エッジ・距離・向きを本線の正規進捗から分離。0.65秒のUターンで実際の進行方向を反転し、回転中の再入力を抑止する。
- `emergency-driving.js` / `driving.js`：通常5車種の既存エンジンを維持し、緊急3車種は正方向チェックポイント・当該周任務・ライン再通過の3条件で周回を成立させる。未達成通過は遡及加算しない。作業中も時計・ライバル・歩行者は進む。ライバル先着後も続行し、2任務＋正規2周で順位を併記したヒーロークリア。
- `missions.js`：3候補／コース／車種、各周1件ずつ別候補をシード抽選。通知は分岐手前。消防は2〜3火を順番自由・累積2.5秒ずつ消火。救急は1人をタッチ、隊員の付き添い乗車5秒、自力搬送、病院引渡し5秒の完了で成功。病院は2か所から抽選。警察は独立車両が通常最高速の75%で環状路を巡航し、同経路で約10m＋サイレンの条件で停止、車両タッチ後の確認5秒で成功。捕獲前の距離補正・待機・ワープ・リセットなし。捕獲後は両車が物理的に異なる停止レーンへ寄せ、重なりを避けてから確認操作へ進む。
- `render/mission-world.js` / `render/circuit.js` / `render/terrain.js`：既存PBRを再利用した実走支線・建物・色の異なる病院、人物・炎・放水・成功時水しぶき。3D作業カメラと3D対象に対応する大きいタッチ領域。消防の全炎を同じ固定カメラに収める。山道の路面・建物に支持構造を配置し、地形を支線より下に保つ。合流カーブの半径と路面法線を検査し、ガードレール・縁石の開口を実道路の位置から生成する。
- `mission-ui.js` / `game-main.js` / `index.html` / `style.css`：任務数、無線・テキスト・イラスト、経路矢印、支線・病院・向き・往復案内線の地図。作業中は運転ボタンと入力を停止、終了後に通常視点・自動発進へ復帰。消防・救急は指令でサイレンON、警察は手動、全車成功時OFF、手動切替可。日本語音声は端末ローカル音声のみを選択し、ミュート・未対応時は画面表示で案内する。
- 診断へ道路・方向・任務状態・経路・作業カメラ・タッチ対象・シードを読み取り専用で追加。任務進捗はポーズ・背景化・コンテキスト復旧で保持し、押下状態は解除。既存のパーツ・AI難易度・パンク修理・歩行者ペナルティ・画質3モード・オフライン・旧HTMLエントリ互換を維持。バンドル・整合性記録・キャッシュを8.0.0に更新。

ローカルWebKitで3シナリオ（消火と解除・ポーズ・GPU復旧、付き添い乗車〜病院自動引渡し、追跡〜警察確認、各自力帰還）が成功。その後の最終合流曲線・地図案内線の調整は単体テスト済みで、現コミットの全ブラウザ検証はPRのCIおよび最終報告に記録する。ブラウザテストは実際のキー・タッチ領域・Uターン・サイレンを操作し、プレイヤー位置や任務完了を強制変更しない。ブラウザは通常の既定シード12345を用い、車種・コース・シードの60組合せは単体側で別に完走検査する。レースシードの乱数1回だけを固定し、描画ライブラリの乱数を固定しない。

初回CIでは同一オリジン検査のローカルURLがバージョン更新の置換で127から128へ変わっていた誤りを検出し、検査対象のURLを127.0.0.1へ復元した。実際の外部アクセスが発生したという結果ではない。ChromiumではGPU復旧後の次フレームを待たずにテストがタッチ対象の座標を読んだため1件失敗し、可視状態を待つよう検査手順を修正。テストのレース乱数固定はリセットが1回取得するまで維持し、取得直後に元へ戻す。警察の停車位置を20パターンで追加検査し、最も近い車体中心が約0.47mとなる例を検出したため、捕獲後の滑らかな寄せ停車と停止レーン間隔の検査を追加した。

開発中、地図の生成でArray.fromのコールバック引数を誤って参照するエラー、および山道の合流路面の折返しを検出して修正。後者は候補を本線両端から安全に接続可能な場所へ再配置し、接線・幅・曲率・法線・地形の検査を追加した。
