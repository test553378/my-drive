# Ver.7：承認済み画質のゲーム全体への統合

画質確認ページ graphics-p2.2 についてユーザーの承認を受け、Phase 3・4・5を統合する。既存のゲーム機能を残したまま、ゲーム本体も Three.js 0.187.0 / WebGL 2 に移行する。広告・課金・個人情報収集は追加しない。外部CDN・外部フォント・計測サービスを実行時に使わない。

## 主な変更

- `game.js`：既存UI・音・操作・レース進行を新しい描画基盤へ接続。読み込み進捗、画質設定、背景移行・停止・明示再開を維持。
- `render/`：PBR・HDR環境反射・実際の影・カメラ・車体と車輪・各種イベントを描画。試作と同じ材質、照明、露出、路面画像、画素数上限を使う。
- `driving.js`：左右操作の解除で横移動を停止し、通常は10秒を超えても現在位置を保持。カーブでも勝手に中央へ戻さない。修理・コース復帰で必要な補正は維持。
- `rival-ai.js`：3段階の難易度（初期値「ふつう」）、4種類の特性、先読みの減速、レースライン、追い越し・側方車両・障害物回避。車種の最高速度と加減速・横移動の上限を守る。順位で速度や位置を強制調整しない。
- `service-worker.js`：Ver.7の完全なオフライン用構成へ更新。メインバンドル、全モデル・路面・HDRとライセンス文書を初回オンライン時に保存する。
- `game.bundle.js`、`game-assets.json`：固定ライブラリを自己配信し、素材のサイズ・SHA-256・三角形数を記録する。

## 車両とコース

8車種と4コースを維持する。NOVA Rは承認済み外部GLBを使用。AERO Sは同じライセンス付きモデルの屋根・側窓等を外したタルガ型、GUARDは独自の塗り分け・警告灯を加えた派生とする。単なる色替えだけでモデルを区別しない。残る5車種は専用のオリジナル造形を新描画基盤で表示し、角を丸めたパネル、車輪開口、窓・室内・装備・金属材質を追加する。

タイヤ・ボディ幅・エアロの全選択を維持。車輪は距離に応じて回転し、前輪のみ操舵する。前輪の初期−30度補正を維持する。外部モデルの車輪順をダメージ判定の順に揃え、仕様上の半径・前後位置をモデルの実寸へ合わせる。救急車等のサイレンと警告灯、バイクの傾きと復旧、パンク・修理表示を維持する。

全コースで同じ実写由来のアスファルト・法線・粗さ画像を使う。マウンテンは高低差・斜面・トンネル、シティは建物・交差点・横断歩道、グランプリは観客席などを実際の3D形状で配置する。修理エリアにはガードレールの切れ目と緑色の進入口を設ける。背景HDR画像だけをコースとして見せる方式ではない。

## 負荷・保存・エラー

- 軽量48万／標準95万／高画質145万画素。影は512／1024／2048。初期値は標準。動作診断から変更でき、自動調整を解除することもできる。
- プレイヤーは標準・軽量100,756三角形、高画質213,195三角形。遠距離用GLBは28,229三角形・画像なしの明示的LOD（プレイヤーの読み込み失敗時の代用品ではない）。車種・材質・周辺設備の統合やインスタンシングを用いる。
- 読み込み中は開始を無効化し、取得済み容量を表示。HTTP失敗・サイズ／SHA不一致・シェーダー失敗を診断に残し、不明な場合に単純図形や2Dへ黙って置き換えない。
- GPU喪失時に古いGPUリソースを解放し、復帰時に反射と影を再構築する。レースは停止を維持し、明示操作で再開する。背景から戻っても経過時間で先へ飛ばない。
- 初回オンライン保存完了後、ゲーム本体の素材・ライセンスをオフラインで使える構成。Safari実機の容量不足・消去・ホーム画面運用までは保証しない。

## AIの検証と公平性

`docs/AI-BASELINES.json` は4コース×3難易度、各4台のAIだけで2周した基準タイム。プレイヤーや障害物・歩行者を除いた再現可能な基準値で、実レースのタイムを約束するものではない。`node scripts/benchmark-ai.mjs` で再計算できる。

ライバルにも同じパンク判定・修理・歩行者接触ペナルティと停止処理を適用する。進行中の横断歩道では先読みして減速・停止する。ゴール済み車を追い越せず最後の車が止まる問題、横に並んだ車が同じレースラインへ合流する問題を走行テストで検出して修正した。

## 素材とライセンス

新しい配布元・有料素材・依存は追加しない。既存 Car Concept（Eric Chadwick / DGG、CC-BY-4.0、元 Unity Fan CC0）とPoly Havenの路面・HDR（CC0）、Three.js／MeshoptDecoder（MIT）を維持する。原本・作者・変更内容とロゴ除外は `graphics-lab/credits.html` と同梱ライセンスを参照。追加ファイル `concept-rival.glb` は既存のロゴ除去済みモバイルGLBから作る派生。画像を除去して約0.55MBに抑え、不要な中間ファイルを配布しない。

## 検証範囲

構文・整形、実素材ハッシュ、車輪軸、8車種×4コースの走行・位置保持、AI、PBRメッシュ、全コースの道路を単体で検証する。ブラウザでは8車種、パーツの全組み合わせ、4コース、左右入力・解除、パンクと自動修理、歩行者への警告とブレーキ、GPU復帰、オフライン、画質切替と失敗診断を検証する。最終件数・成否はPRと作業記録に報告する。

Linux Playwright WebKitのオフラインナビゲーションには既存の無関係な最小ページでも再現する問題があり、その1項目は除外を維持する。Chromiumの実オフライン遷移と両ブラウザの保存内容を確認する。

**iPad第9世代実機のFPS、発熱、電池・メモリ、連続タッチ、長時間走行、Safari・ホーム画面のオフライン起動は未検証。** この環境のソフトウェア描画のFPSをiPadの性能値として報告しない。受け入れ確認は、まず標準画質で8車種・4コースを試し、重ければ軽量へ変更し、正常時の位置保持・修理・横断歩道を確認する。

既存GitHub Actions定義・リポジトリ設定は変更しない。従来のビルドコマンドで試作とゲーム本体の両バンドルを生成し、CIでは生成物がコミット時の内容と変わればエラーにする。開発はPhaseごとのコミットを1つのPRへまとめる。
