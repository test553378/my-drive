# Ver.8 道路・進入案内の改善計画

基準 main `2836383`。今回は公開・自動マージせず、1ブランチ・1PRで確認に提出する。Actions・リポジトリ設定、外部素材・依存は変更しない。

確認した原因：進入路の初期接線が本線へ直角、分岐選択がノード通過瞬間の押下のみ、描画と地図が全候補・全施設を常設している。

- 本線の形状・高さに沿う広い進入部、並走区間、滑らかな接続曲線と帰路を作る。路面法線・接線・幅・接続・他道路との干渉を検査する。
- そのレースの車種・抽選2任務・搬送先から有効道路グラフを作り、走行・衝突・施設・経路探索・地図・3D案内を共用する。任務完了では削除せず、次レースでのみ切り替える。
- 合法な進行方向を考慮した経路探索と、進入手前の左右操作を保持する短い入力受付区間を設ける。自動で目的地へ移動せず、左右操作で選択する。
- 路面上の明るい矢印・曲線状の案内を目的地／復帰経路へ沿わせ、接近時に強調する。HUD・ミニマップと同じ経路を使う。
- 本線と進入路が並走・共用する区間の歩行者・ライバル接触も維持し、周回の判定は既存の正規本線チェックポイントに限定する。
- 3車種×4コース×5シードの完走、早めのタップと逆走再進入、表示・経路・衝突の一致、既存回帰、Chromium/WebKitの実操作を検証する。iPad第9世代実機は別の未検証項目として記録する。
