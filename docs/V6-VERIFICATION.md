# Ver.6 要件対応・検証報告

対象：添付「Ver.4.1 統合要件定義書」。公開済みVer.5の続版として、実装版番号を6.0.0としています。対象機種はiPad第9世代。広告・課金・個人情報入力・解析・実行時外部素材配信はありません。

## 要件と実装

| 要件 | 実装・検証対象 |
|---|---|
| FR-01 パンク | 4種類の3D障害物、車体寸法に応じた掃引衝突、衝撃16m/s以上、最寄り車輪を判定。バイクは前後2輪。軽い接触では減速のみ。タイヤの縦方向圧縮、車体揺れ、空気音、警告、弱い片流れ。最高速度60%、加速65%、操舵68%、ターボ禁止。設定は `race-config.js` |
| FR-01 修理 | 各コース3箇所の緑の修理レーン。看板・レンチ・地図の緑マーカー・操作案内、自動誘導（手動上書き可能）、約3秒停止・タイヤ復元・回転レンチ・音、正常性能への復帰 |
| FR-02 車両 | 既存2台を残して8台・7カテゴリー。トラック／バス／ヘルメットライダー付きバイク／パトカー／救急車／消防車は独自形状・寸法・性能。全車最初から選べ、色・パーツ・回転プレビュー対応。バイクの傾き／パンク時の自動復帰、緊急車両のサイレン切替・点滅（速度不変） |
| FR-03 コース | 4つの閉じたCatmull–Rom曲線を距離で走行。初級1400m、山1650m、街1500m、GP1850m。幅・曲率・高低差・景観が異なる。プレビュー／全体地図／自車位置、各周8チェックポイント、ショートカット拒否、コース外復帰、旋回速度の影響、走行ラインによる距離差 |
| FR-04 歩行者 | 街の横断歩道のみ、走行ごとの乱数、回避反応時間・制動距離以上の事前警告。歩行アニメーション、全車ブレーキ。接触で安全な歩道へ移動し、3秒停止＋10秒加算を一度だけ適用。最終順位も時間加算を反映。AIも横断で停止。待っていれば加算なし。負傷・吹き飛び表現なし |
| FR-05 タッチ | UIは `manipulation`、走行ボタン／描画面は `none`、メニューのスクロール／ピンチとアクセシビリティを保持。ゲーム領域に限定した補完。ポインター単位の入力所有権、キャンセル・フォーカス喪失・停止時の解除 |
| 非機能 | WebGL 1、従来の初期化段階別診断・コンテキスト復旧・動的解像度・一時停止を維持。描画は前方近傍チャンクのみ。切替時に旧コースGPUバッファを破棄、車体20／エアロ12のキャッシュ上限。Pagesのサブディレクトリ対応、21ファイルを版別キャッシュ |

既存WebGL初期化失敗の確認済み原因は、旧版の頂点／フラグメント間の共有uniform精度不一致です。Ver.4以降の修正と診断を維持しています。[原因の再現と調査記録](VERIFICATION.md)。今回、新たなiPad固有の初期化原因を推測で断定していません。

## 検証結果

自動テストはLinux上のNode.js 24、Playwright 1.56.1（Chromium／WebKit）。タッチ設定と1080×810／810×1080の画面寸法を使用しますが、A13 GPU・iPadOS・実際のMobile Safariを再現しません。

- 単体テスト：35件成功。8車両×4コースの全32組合せで2周・16チェックポイント、全32組合せのパンク後誘導・修理、各車輪の損傷、停止・歩行者・順位・入力所有権を含む。
- 構文・整形・差分チェック：成功。
- ブラウザーテスト：26ケース×2ブラウザーを用意し、Linux WebKit固有のオフライン1ケースを理由付きで除外します。実際の成否・所要時間・スクリーンショットは[最終コードのCI実行](https://github.com/test553378/my-drive/pull/3/checks)で確認できます。左右の画面投影、全8車両の出走、全4コースの選択・描画、パンクから修理までの実操作、街での制動待機、2周完走、パーツの描画差、画面回転、複数指の入力所有権、WebGL失敗注入・復旧、キャッシュを含みます。
- 公開反映はGitHub Pagesのデプロイ完了後に、配信ファイルの一致とWebKitでの公開URLの起動・左右操作・車両とパーツ・コース選択・ブレーキを確認します。これはiPad実機確認の代わりにはなりません。

実操作によるパンク→修理のブラウザーテストで、自動中央復帰と修理誘導が競合する不具合を発見しました。誘導中は中央復帰を止め、全車両×コースの誘導完了テストを追加しました。修理レーンへ入った状態だけを検証するテストでは検出できなかったため、開始前からの連続動作も検証しています。

既知の検証環境制約：Linux Playwright WebKitのオフラインナビゲーションは、無関係な最小Service Workerページでも内部エラーになります。理由付きで1ケースだけ除外し、Chromiumの実オフライン起動と両ブラウザーの全21ファイルキャッシュは別途検証します。詳細と再現方法は[初期検証報告](VERIFICATION.md)。
