# Ver.8.0.1 ミッション用道路・進入案内

基準: main `2836383` / 作業ブランチ `feat/ver8-road-guidance`。PRで確認する変更。mainへのマージ・公開は今回行わない。

## 調査と修正

既存コードでは、進入路の開始方向が本線に対して約90度、分岐選択はノード通過瞬間の押下だけだった。描画と地図は全候補3か所・全病院を生成し、選択車種・抽選2任務による表示制御がなかった。

- `roads.js`, `service-layouts.js`: 80mの進入・並走部、60mの合流部、接線をそろえた5次ベジェ接続曲線。12m幅の支線へ幅を漸変。本線の形状・高さに沿って分岐し、帰路は入口の30m手前に戻るため、周回の正規チェックポイントを飛ばさない。配置探索は開発時のみ `scripts/search-service-layouts.mjs` で実行し、確定した制御値から起動時に生成する。
- `raceRoadGraph`: 車種・抽選2任務・選択された搬送先から有効な道路／施設を確定。描画、走行可能な接続、物理接触、経路探索、ミニマップが共用する。任務完了後も道路は残し、次のレースで切り替える。
- `render/road-guidance.js`, `mission-ui.js`: 路面上に最大250m先まで水色の矢印と曲線状のライン。分岐付近は黄色・拡大し、車両の接近に伴い強調する。目的地、搬送先、本線復帰、通過後のUターンに追従。既存HUDと地図も同じ経路を使う。最大24矢印・固定長の動的バッファを使用し、入力を遮るDOM要素は増やさない。
- `emergency-driving.js`: 分岐140m手前から正しい左右入力を保持。放しても分岐を選択し、反対入力・左右同時入力・Uターンで取り消す。操作していなければ本線を直進する。本線と支線が舗装を共用する区間では、周回進捗と独立した実際の位置で歩行者・障害物・ライバルの接触を処理する。
- `render/mission-world.js`, `render/circuit.js`, `render/game-renderer.js`, `graphics-lab/src/scene.js`: 有効道路だけを生成。本線の縁線・縁石・ガードレールと支線の開口を整合し、重複舗装のちらつきを抑制。消防の現場、救急の現場・病院、警察の道路を車種ごとに表示。
- 既存素材・ライセンスは維持。外部素材・依存追加なし。広告・課金・通信による情報収集の追加なし。Actions、権限、リポジトリ設定は変更しない。
