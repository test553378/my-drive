# Ver.8.0.4 分岐・合流の改善と検証

対象仕様: [2026年11月25日の添付仕様書](V8-SHALLOW-JUNCTIONS-REQUIREMENTS.md)。比較元はmainの `4b43d5b`（8.0.3）。この改修はPRで提出し、確認前にはマージ・公開しない。

## 調査結果と修正

接続点だけを見ると本線との方向はほぼ一致していた。一方、分岐・合流途中には最大約20～28度の方向差があり、環状路から復帰路への接続には約90度の向きの不連続があった。これらはコードと経路の計測で確認した事実であり、幼児の操作への影響は実機での再確認が必要。

- 横移動を105 station-m、並走を20 station-mとする5次曲線へ変更。横方向の1・2階微分を両端で0にする。距離は本線の基準距離であり、実際の曲線の長さとは異なる。実際の並走区間は約17～36m。直線で45m/sの場合、横移動区間は約2.3秒に相当する。
- 復帰路は環状路の接線方向から滑らかに離れ、並走後に本線へ同方向で合流する。環状路は無操作なら周回を続け、出口は既存の左右操作で選ぶ。新しい自動運転やボタンは追加しない。
- 走行可能幅、接触する本線位置、舗装、白線、路肩、案内・ミニマップを同じ有効道路グラフに追従させる。接合部では舗装のちらつきと内側の白線を抑える。
- 現場位置と連絡路を再配置。自己交差、環状路への侵入、他の道路との干渉を検査する。探索は開発時だけ実行し、起動時は固定の制御点を読み込む。
- 山道では高さ6m未満の交差を除外し、安全な立体交差だけを許す。下の道路に支柱を置かず、異なる高さの道路のために本線のガードレールを開けない。地形は拡張した道路範囲を覆い、低い方の道路より下に保つ。地形の分割数は約2万セルに制限する。
- 合流位置は入口の30m手前を維持。チェックポイントを飛び越える変更は行わず、既存の周回台帳・逆走・未達成時の判定を維持する。
- バージョンとオフラインキャッシュを8.0.4へ更新。外部素材・依存ライブラリ・GitHub Actions設定は追加・変更しない。
